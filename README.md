# АлтайАвиа — новый сайт

Статический многостраничный сайт авиакомпании «АлтайАвиа» с интерактивными 3D-моделями
вертолётов парка (Eurocopter AS350, Ми-8АМТ, Ми-171). Готов к размещению на любом хостинге —
папка `site/` целиком и есть сайт.

## Структура

```
site/                    ← готовый сайт (загрузить на хостинг как есть)
  index.html             главная
  arenda.html            аренда (тарифы, назначение, способы заказа, форма)
  ekskursii.html         экскурсии → два направления
  ekskursii/gornyj-altay.html, ekskursii/altay-village.html
  ekskursii/<маршрут>.html   30 страниц маршрутов с ценами и формой заказа
  ploshchadki.html, servis.html, o-kompanii.html, galereya.html
  onlajn-oplata.html, kontakty.html, zakaz-poleta.html
  politika.html          политика конфиденциальности (текст сохранён дословно)
  sout.html              документы СОУТ
  vertolety/as350.html, mi8amt.html, mi171.html   страницы бортов с 3D
  css/main.css           стили
  js/heli3d.js           процедурные 3D-модели вертолётов + просмотрщик (three.js r128)
  js/fleet.js            подключение 3D-сцен к страницам (ленивая загрузка, fallback)
  js/main.js             меню, формы, галерея, версия для слабовидящих
  img/3d/                статичные рендеры моделей (для прайса, карточек и fallback без WebGL)
  img/…, docs/…          фотографии и PDF с текущего сайта
data/                    исходные данные (маршруты, политика)
build/build.py           генератор страниц: python3 build/build.py
build/dev/               dev-3d.html, _views.html (просмотр моделей), _capture.html (рендер PNG)
site/models/             импортированные модели: <key>.js (компактный формат сайта) + <key>.jpg (текстура)
```

## Как править

* Тексты и цены — в `build/build.py` (страницы) и `data/excursions.json` (маршруты),
  затем `python3 build/build.py`. Можно править и готовые HTML в `site/` напрямую.
* Формы заявок: в `site/js/main.js` задайте `CONFIG.formEndpoint` — URL обработчика,
  принимающего POST JSON. Пока он пуст, заявка открывает письмо на `info@altay-avia.ru`.
* Онлайн-оплата: формы на `onlajn-oplata.html` готовы к подключению платёжного шлюза банка
  (замените обработчик отправки на редирект в форму эквайринга).
* 3D: ливреи и геометрия — `site/js/heli3d.js` (`LIVERY`, `buildAS350`, `buildMi8`). Модели можно
  только вращать (зум отключён). Сцены есть только на главной (герой + «Парк») и на страницах бортов.
  Импортированные модели лежат в `site/models/<key>.js` + `<key>.jpg` — это компактный формат сайта
  (`build/import/glb2js.py`): файл подключается обычным `<script src>`, геометрия распаковывается в
  `heli3d.js` (`Viewer.loadPacked`), текстура грузится как картинка. Никаких GLTFLoader/WebAssembly/fetch —
  поэтому работает и в песочнице артефакта claude.ai, где fetch/blob/wasm могут быть запрещены.
  Пересоберите сайт (`python3 build/build.py`) после добавления/удаления файлов — список моделей
  попадает в `<html data-models>`; ключи без файла показываются процедурными.
  Для просмотра моделей: скопируйте `build/dev/dev-3d.html` или `build/dev/_views.html` в `site/`
  и откройте через локальный сервер. Для перерендера PNG — `build/dev/_capture.html` + `python3 build/save_server.py`.
* 3D-сцены стоят в процедурном пейзаже долины Катуни (`makeLandscape` в `heli3d.js`): площадка «Карасук»,
  река, тайга (InstancedMesh), хребты со снежниками на 1–3 км; главный экран — Ми-171 на площадке,
  сцена во всю ширину, вертолёт смещён вправо (`data-offset`), текст поверх.
* Шрифты: Unbounded (заголовки), Golos Text (текст), Oswald (подписи и цифры) — Google Fonts.
* Анимации (`site/js/main.js`, `css/main.css`): прелоадер «раскрутка винта» (один раз за сессию),
  шторка при переходе между страницами, прилёт 3D-вертолёта на главной и его «отлёт» при прокрутке,
  трасса полёта с точками маршрута, табло вылетов в стиле split-flap, счётчики-«альтиметры»,
  наклон карточек за курсором, бегунок меню, бегущий блик на кнопках. Всё отключается при
  `prefers-reduced-motion`.

## Импорт готовых 3D-моделей (Sketchfab / TurboSquid)

Скачивать модели нужно из-под вашего аккаунта (Sketchfab отдаёт файлы только авторизованным
пользователям, TurboSquid — после покупки). Дальше всё автоматически:

1. На странице модели: **Download 3D model → glTF** (нужен бинарный `.glb`). Файл положите в `build/import/`.
2. Посмотрите имена узлов и материалов: `python3 build/import_model.py list build/import/model.glb`
3. Примените конфиг ливреи (удаление военных узлов + перекраска):
   `python3 build/import_model.py apply build/import/model.glb site/models/mi8amt.glb --config build/import/mi8amtsh.json`
   Если какие-то узлы остались/пропали лишние — поправьте список `delete` в конфиге (подстроки имён, без учёта регистра).
   Масштаб/поворот — в секции `transform` (сайт ждёт метры, нос по +X).
4. `python3 build/build.py` — страницы получат список моделей, сайт покажет их вместо процедурных,
   а в подвал добавится атрибуция (для CC BY она обязательна).

### Ми-8АМТ и Ми-171 — уже импортированы

`site/models/mi8amt.js` и `site/models/mi171.js` (по ~3,8 МБ, + текстуры `.jpg` по 0,6 МБ) собраны из «Mil Mi-8AMTSh» (42manako, Sketchfab,
CC BY 4.0 — атрибуция добавляется в подвал автоматически). Исходник лежит в `build/import/mi8amtsh/`.
Конвейер (если нужно перекрасить/пересобрать):

1. Скопируйте `build/dev/_bake.html` в `site/`, папку `build/import/mi8amtsh` — в `site/_import/`,
   запустите `python3 build/save_server.py` и локальный сервер; откройте `/_bake.html?livery=mi8amt`
   и `/_bake.html?livery=mi171` — ливрея запекается в UV-развёртку (цвета, полосы, надписи задаются в шейдере).
2. `./build/import/build_mi8.sh` — склеивает запечённую ливрею с оригинальной текстурой (стёкла, детали),
   удаляет вооружение (список `DELETE` в `pack_mi8.py`), переводит модель в метры/оси сайта, создаёт
   узлы `MainRotor`/`TailRotor` для анимации, упрощает сетку (gltf-transform simplify, error 0.003 ≈ 160 тыс.
   треугольников) и пакует в `site/models/<key>.js` (`glb2js.py`). Рядом пишется и `.glb` (meshopt) — запасной
   формат для обычного хостинга, сайтом не используется.
3. Статичные рендеры для карточек: `build/dev/_capture_glb.html` → `site/img/3d/`.

AS350 остаётся процедурной (`js/heli3d.js`): из присланных ссылок обе AS-350 на Sketchfab не скачиваются
(zizian — платная, $25.49), модели TurboSquid — платные. Если купите модель — `build/import/as350.json`
и `import_model.py apply` перекрасят её; при нестандартных именах узлов используйте подход из `pack_mi8.py`.
