# АлтайАвиа — новый сайт

Статический многостраничный сайт авиакомпании «АлтайАвиа» с интерактивными 3D-моделями
вертолётов парка (Eurocopter AS350, Ми-8АМТ, Ми-171). Готов к размещению на любом хостинге —
папка `site/` целиком и есть сайт.

## Структура

```
site/                    ← готовый сайт (загрузить на хостинг как есть)
  index.html             главная
  arenda.html            аренда (тарифы, назначение, способы заказа, форма)
  ekskursii.html         экскурсии → два направления
  ekskursii/gornyj-altay.html, ekskursii/altay-village.html
  ekskursii/<маршрут>.html   30 страниц маршрутов с ценами и формой заказа
  ploshchadki.html, servis.html, o-kompanii.html, galereya.html
  onlajn-oplata.html, kontakty.html, zakaz-poleta.html
  politika.html          политика конфиденциальности (текст сохранён дословно)
  sout.html              документы СОУТ
  vertolety/as350.html, mi8amt.html, mi171.html   страницы бортов с 3D
  css/main.css           стили
  js/heli3d.js           процедурные 3D-модели вертолётов + просмотрщик (three.js r128)
  js/karasuk.js          сцена площадки «Карасук» (рельеф, снимок, ангары, лес, река)
  js/fleet.js            подключение 3D-сцен к страницам (ленивая загрузка, fallback)
  js/main.js             меню, формы, галерея, версия для слабовидящих
  img/3d/                статичные рендеры моделей (для прайса, карточек и fallback без WebGL)
  img/…, docs/…          фотографии и PDF с текущего сайта
data/                    исходные данные (маршруты, политика)
build/build.py           генератор страниц: python3 build/build.py
build/dev/               dev-3d.html, _views.html (просмотр моделей), _capture.html (рендер PNG)
site/models/             импортированные модели: <key>.js (компактный формат сайта) + <key>.jpg (текстура)
site/scene/              данные сцены «Карасук» (build/terrain/build_karasuk.py)
```

## Как править

* Тексты и цены — в `build/build.py` (страницы) и `data/excursions.json` (маршруты),
  затем `python3 build/build.py`. Можно править и готовые HTML в `site/` напрямую.
* Формы заявок: в `site/js/main.js` задайте `CONFIG.formEndpoint` — URL обработчика,
  принимающего POST JSON. Пока он пуст, заявка открывает письмо на `info@altay-avia.ru`.
* Онлайн-оплата: формы на `onlajn-oplata.html` готовы к подключению платёжного шлюза банка
  (замените обработчик отправки на редирект в форму эквайринга).
* 3D: ливреи и геометрия — `site/js/heli3d.js` (`LIVERY`, `buildAS350`, `buildMi8`). Модели можно
  только вращать (зум отключён). Сцены есть только на главной (герой + «Парк») и на страницах бортов.
  Импортированные модели лежат в `site/models/<key>.js` + `<key>.jpg` — это компактный формат сайта
  (`build/import/glb2js.py`): файл подключается обычным `<script src>`, геометрия распаковывается в
  `heli3d.js` (`Viewer.loadPacked`), текстура грузится как картинка. Никаких GLTFLoader/WebAssembly/fetch —
  поэтому работает и в песочнице артефакта claude.ai, где fetch/blob/wasm могут быть запрещены.
  Пересоберите сайт (`python3 build/build.py`) после добавления/удаления файлов — список моделей
  попадает в `<html data-models>`; ключи без файла показываются процедурными.
  Для просмотра моделей: скопируйте `build/dev/dev-3d.html` или `build/dev/_views.html` в `site/`
  и откройте через локальный сервер. Для перерендера PNG — `build/dev/_capture.html` + `python3 build/save_server.py`.
* 3D-сцены стоят на настоящей площадке «Карасук» (реальный рельеф, спутниковый снимок, ангары по фото —
  см. раздел «Сцена «Карасук»» ниже; код — `site/js/karasuk.js`). Если данные не загрузились — процедурный
  пейзаж (`makeLandscape` в `heli3d.js`). Главный экран — Ми-171, сцена во всю ширину, вертолёт смещён
  вправо (`data-offset`), текст поверх; на вкладках «Парка» и страницах бортов камера наводится на долю
  высоты модели (`data-ty-rel`).
* Шрифты: Unbounded (заголовки), Golos Text (текст), Oswald (подписи и цифры) — Google Fonts.
* Дизайн v3 «Небо Алтая» (`css/main.css`, `js/main.js`, разметка — `build/common.py`, `build/index_page.py`): главная построена как
  полёт от «Карасука» (375 м) к Белухе (4506 м): герой с живой 3D-сценой и «взлётом» вертолёта по прокрутке и приборами
  (высота, курс, борт) → бегущая строка направлений (скорость зависит от прокрутки) → «Время в пути» (закреплённый экран
  с видом из кабины и иллюминатором, 3 отрезка маршрута) → горизонтальная лента направлений → компания и бортовой журнал
  → парк в 3D → табло вылетов → услуги-фотокарточки → общий для всех страниц блок «Ваш полёт над Алтаем начинается здесь».
  Анимации: прелоадер «набор высоты» (один раз за сессию), переход между страницами «диск винта» из точки клика,
  шапка прячется при прокрутке вниз, полноэкранное меню, местное время Алтая (UTC+7), высотомер прокрутки справа (≥1680 px),
  слова заголовков из-под маски, фото шторкой, параллакс, счётчики, split-flap табло, наклон карточек, магнитные кнопки,
  курсор-кольцо с подписью над 3D и карточками. Всё отключается при `prefers-reduced-motion`.
* Истинный масштаб бортов: `data-true-scale="1"` у 3D-сцены (парк на главной, страницы бортов) — камера рассчитана по
  габаритам Ми-8 (`REF` в `js/fleet.js`), поэтому Ми-8АМТ и Ми-171 видны почти вдвое крупнее AS350; внизу сцены — шкала «10 м».
  На карточках и в прайсе рендер AS350 уменьшен так же (`SCALE_K` в `build/build.py`).
* Обложки внутренних страниц — полноэкранные фото из галереи (аргумент `image` у `band()` в `build/build.py`).

## Импорт готовых 3D-моделей (Sketchfab / TurboSquid)

Скачивать модели нужно из-под вашего аккаунта (Sketchfab отдаёт файлы только авторизованным
пользователям, TurboSquid — после покупки). Дальше всё автоматически:

1. На странице модели: **Download 3D model → glTF** (нужен бинарный `.glb`). Файл положите в `build/import/`.
2. Посмотрите имена узлов и материалов: `python3 build/import_model.py list build/import/model.glb`
3. Примените конфиг ливреи (удаление военных узлов + перекраска):
   `python3 build/import_model.py apply build/import/model.glb site/models/mi8amt.glb --config build/import/mi8amtsh.json`
   Если какие-то узлы остались/пропали лишние — поправьте список `delete` в конфиге (подстроки имён, без учёта регистра).
   Масштаб/поворот — в секции `transform` (сайт ждёт метры, нос по +X).
4. `python3 build/build.py` — страницы получат список моделей, сайт покажет их вместо процедурных,
   а в подвал добавится атрибуция (для CC BY она обязательна).

### Ми-8АМТ (RA-24187) и Ми-171 (RA-25565)

`site/models/mi8amt.js` и `site/models/mi171.js` (~3,6 МБ, + текстуры `.jpg` 4096 px ~1,5 МБ) собраны из
«Mil Mi-8AMTSh» (42manako, Sketchfab, CC BY 4.0 — атрибуция в подвале). Исходник — `build/import/mi8amtsh/`.
Ливреи повторяют фото бортов компании из галереи сайта. Пересборка одной командой:

    ./build/import/build_mi8.sh            # или ./build/import/build_mi8.sh mi171

* `mi8_geom.py` — общая загрузка: удаление вооружения, экранов ЭВУ, кассет ловушек и бронеплит кабины (список `DELETE`),
  глухой части сдвижных панелей-блистеров и обшивки капота под выхлопными патрубками (`DROP_TRIS`), метры и оси сайта,
  центры втулок, палитра в свободном углу атласа (стойки/шины/диски, рамки, патрубки, обтекатель радара + градиент
  внутренней поверхности патрубка), список окон салона, проёмы остекления кабины (`cockpit_loops` — граничные петли обшивки),
  параметры выхлопных патрубков (`EXHAUST`);
* `mi8_nose.py` — нижние окна носа (у Mi-8AMTSh нос глухой): контур задан в развёртке носа и переносится на обшивку лучами;
* `livery_mi8.py mi8amt|mi171` — перекраска исходной камуфляжной текстуры по 3D-координатам текселей
  (как у AS350): швы и заклёпки сохраняются, военные знаки стираются; цвета, граница «волны», надписи
  и флаги — в классах `Mi8AMT` / `Mi171`;
* `pack_mi8.py` → gltf-transform simplify (≈150 тыс. треугольников) → `glb2js.py` → `mi8_extras.py`:
  окна салона (у исходника — сквозные круглые проёмы): у Ми-8АМТ — тёмное стекло с ободком, у Ми-171 —
  прямоугольные VIP-окна в серебристых рамках (патчи повторяют изгиб обшивки); остекление кабины — прозрачное стекло
  в проёмах (лобовые, боковые, блистеры целиком, нижние окна), у Ми-171 всё остекление в серебристой окантовке;
  выхлопные патрубки двигателей под несущим винтом (бронзовый срез, копоть в глубине); у Ми-171 — обтекатель
  метеорадара внизу носа и краска-металлик. Изнанка обшивки (видна сквозь стёкла) в `heli3d.js` — серая, как салон.
* Номер Ми-171 на балке — по фото борта: высота букв ≈0,3 м, центр под антенной на балке (x≈−6), флаг отдельно ближе к хвосту
  (`Mi171.decals()` в `livery_mi8.py`).
* Статичные рендеры: `build/dev/_capture_packed.html?m=mi171` (+ `save_server.py`) → `build/dev/trim_renders.py mi171`.

### Eurocopter AS350 (RA-04062)

Источник — модель «Eurocopter AS350 Squirrel» от FlightGear UK (https://github.com/FGMEMBERS/AS350,
GPL-2.0; атрибуция в подвале добавляется автоматически). Нужные файлы лежат в `build/import/as350src/`
(формат AC3D, текстуры ливреи default 2048 px, салон, рулевой винт).

1. `python3 build/import/pack_as350.py` — всё в один шаг, без браузера и gltf-transform:
   * `ac3d.py` разбирает AC3D; оси переводятся в оси сайта, нормали сглаживаются по углу излома;
   * рулевой винт собирается из `TailRotor/*.ac` по смещениям из `AS350-Squirrel.xml`, у несущего винта
     своя развёртка (лопасть — текстура `_blade`), центр втулки — по концам трёх лопастей;
   * текстуры сводятся в атлас 4096×2048 (`site/models/as350.jpg`, борта 2048 px, салон 512/256);
   * `livery_as350.py` дорисовывает ливрею по 3D-координатам текселей: белый корпус, синяя «волна» к балке,
     синие полозья, «ALTAY AVIA» за дверями, «RA-04062» на балке, флаг на киле. Панельные швы и запечённые
     тени сохраняются; где один кусок текстуры используют и обшивка, и скрытые грани, побеждает видимая
     снаружи грань (карты глубины с 10 направлений);
   * стекло — меши `m:'glass'` (сильная тонировка, как у борта; у Ми-8 — своя, `data.glass` в модели), модель целиком
     `side:'front'` (грани AC3D односторонние, как в FlightGear).
2. Статичные рендеры: `build/dev/_capture_packed.html` (скопировать в `site/`, открыть `?m=as350`,
   нужен `build/save_server.py`) → `python3 build/dev/trim_renders.py as350`.
3. Осмотр с шести ракурсов: `build/dev/_as350view.html` → `site/img/3d/_check_as350.png` (параметры: `m`, `fit`, `tx`, `ty`,
   `views=θ:φ:подпись|…`, `hl`/`hide` — подсветить/скрыть детали, `bf=1` — изнанка граней пурпурным).
   Сверка с фото: `build/dev/_photomatch.html?cam=…` — рендер камерой, подобранной по фото борта.

## Сцена «Карасук» (фон 3D-просмотра)

Вертолёты стоят на настоящей площадке компании — «Карасук», с. Чепош, 51°33′36″ N, 85°55′03″ E (долина Катуни):

* рельеф — AWS Terrain Tiles (SRTM), снимок — Sentinel-2 cloudless 2016 (EOX, s2maps.eu, CC BY 4.0), ±9 км;
  атрибуция добавляется в подвал автоматически;
* планировка базы — по спутниковому снимку (0,74 м/px) и фото из галереи: четыре ангара фасадами на одной линии
  (белые, синие ворота, синий цоколь; северный — тёмный), перрон с жёлтыми кругами, прямые рулёжки и пять площадок
  в ряд, стоянка с машинами и два дома у неё, тракт с полосой сосен, ветроуказатель; вертолёт — на большой площадке P3;
* трава у площадки — луг (кочки, сухие и тёмные куртины) × рисунок травинок в шейдере рельефа и объёмные кустики
  вокруг площадки (вдали «прорастают» в землю);
* Катунь — по снимку и рельефу, в шейдере — гладкая вода с бликами и рябью; лес — ~10 тыс. деревьев
  (сосна, ель/кедр, берёза) по маске леса на равнине (на склонах гор — только текстура полога): вблизи объёмные,
  вдали — «билборды»; небо с облаками.

Файлы: `site/scene/karasuk.js` (сетка высот, деревья, постройки), `karasuk_sat.jpg` (4096 px, для телефонов —
`_2k`), `karasuk_near.jpg` (детальная текстура базы ±400 м), `karasuk_water.png`; код — `site/js/karasuk.js`.
Пересборка: `python3 build/terrain/fetch_tiles.py` (один раз, кэш в `build/terrain/cache`) и
`python3 build/terrain/build_karasuk.py` (планировка — константы `FACADE_X`, `HANGARS`, `APRON`, `PADS`, `TAXIWAYS`,
`SMALL_BUILDINGS`, `CARS` в начале файла).
Если данные сцены не загрузились, просмотрщик показывает прежний процедурный пейзаж.
